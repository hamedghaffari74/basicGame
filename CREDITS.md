# Credits and asset licenses

The original twelve building sprites (farm, tree lot, stone quarry, flour mill, warehouse, market, shop, solar plant, wind turbine, coal plant, battery, and coal mine) were generated for this project with the built-in image-generation tool and cropped to 128×128 PNGs. New industrial chains and park use individual project-authored SVG illustrations. A short interface sound is synthesized at runtime and can be muted. No third-party art, font, sound, plug-in, or runtime dependency is included.
